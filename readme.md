# Nitin Vishwakarma — Portfolio Website

Minimalist personal portfolio website built with native web primitives.

## Structure

- `index.html` - Main landing page featuring bio intro, photo placeholder, extended text, and interactive mini-game
- `css/` - Minimalist dark navy blue theme styles
- `js/` - Routing engine (`app.js`) and hero interactive canvas mini-game (`game.js`)
- `images/` - Vector graphics, logo, and placeholder assets
- `html files/` - Standalone HTML subpages
